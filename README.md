## 📌 Sobre o Projeto

O objetivo deste projeto é aplicar na prática os conceitos essenciais de Gerência de Configuração, abrangendo:
* Controle de versionamento de código utilizando **Git** e **GitHub**.
* Implementação do fluxo de trabalho baseado em **Git Flow** (`main`, `release`, `development` e branches de `feature`).
* Padronização de **commits semânticos**.
* Criação e revisão de **Pull Requests** para integração contínua de código.

---

## 🌿 Estrutura de Branches

- **`main`**: Código em produção (versão estável/final `v1.0`).
- **`release`**: Branch de preparação e testes para a versão final.
- **`development`**: Branch base para integração das funcionalidades desenvolvidas pela equipe.
- **`feature/*`**: Branches individuais criadas por cada integrante para o desenvolvimento de suas tarefas.
