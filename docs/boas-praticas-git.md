# Boas Práticas de Controle de Versão

## Branches

As alterações devem ser desenvolvidas em branches de funcionalidade,
criadas a partir da branch `development`.

## Commits

Os commits devem ser pequenos, descritivos e seguir um padrão semântico.

## Pull Requests

Após concluir uma feature, deve ser aberto um Pull Request da branch
`feature` para a branch `development`.
